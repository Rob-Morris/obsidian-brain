# v0.54.17

**Migrate typed artefact creation ownership**

- Add granular `artefact.create` request, resolver, result and contributor
  application ownership.
- Keep body content optional so omission selects the authored type template;
  inline and staged content use the shared locality-safe source contract.
- Preserve type-driven naming, parent placement, explicit living keys,
  frontmatter overrides and optional wikilink repair through `create.py`.
- Return parent advice, wikilink findings and applied fixes as bounded typed
  values instead of transport-specific dictionaries.
- Consume staged bodies only after commit, retain them on validation failure,
  and report unexpected post-commit failures as an unknown outcome.
- Cover template-backed and explicit-body creation, parent context,
  frontmatter, staged input, wikilink findings, strict transport and effects.
- Align `src/brain-core/VERSION`, the README badge, and `BRAIN_INSTALL_REF`
  with v0.54.17. `BRAIN_CLI_VERSION` and `PROXY_VERSION` remain unchanged
  because their dispatch and protocols did not change.
