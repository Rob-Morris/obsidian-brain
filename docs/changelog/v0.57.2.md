# v0.57.2

**Summary:** Enforce fail-closed authority and simplify `_application` ownership

**Type:** Brain Core patch; CLI install reference alignment

## Changed

- Require `AuthorityEvaluator.ceiling_allows()` and `AuthorityEvaluator.consume()` at every invocation, and report caught boundary failures through `InvocationContext.diagnostics` with the command, phase and correlation ID.
- Derive `current_application_catalogue()` and `current_request_resolver()` from one `_COMMAND_OWNERS` registry, and remove obsolete pre-consolidation command owners under `_application/{memory,plugin,skill,style,template,trigger,type}`.
- Route strict unknown-field, empty-request and primitive decoding through `_application/_decoding.py`, and reuse `ALL_APPLICATION_PROJECTIONS`, `request_error()` and portable-reader catalogue construction.
- Implement `resource.list` and `resource.read` directly over portable resource readers instead of dispatching through hidden application commands.
- Make `_semantic.runtime.load_embeddings_state()` load only requested arrays, and avoid retrieval-state reads for explicit semantic search, context-only classification and exact filename resolution.
- Align `cli/brain` and `cli/brain.cmd` to install Brain Core v0.57.2 while retaining `BRAIN_CLI_VERSION=2.1.0` because the CLI dispatch surface is unchanged.

## Verification

- `tests/application/test_application_registration.py` proves that request unions, catalogue entries, resolver entries and declared command owners stay aligned.
- `tests/application/test_application.py` and `tests/application/test_access_grant_owners.py` cover fail-closed authority consumption, immutable discriminators and diagnostic reporting.
- `tests/application/test_optional_semantic_read_owners.py` and `tests/test_semantic_model.py` prove that irrelevant lexical indexes and embedding arrays are not loaded.
