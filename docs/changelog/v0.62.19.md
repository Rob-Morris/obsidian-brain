# v0.62.19

**Summary:** Report semantic rebuild failures as structured conflicts

**Type:** Brain Core patch

## Changed

- Catch the known asset-refresh failure family (`SEMANTIC_ASSET_REFRESH_ERRORS`) in `_lifecycle/semantic_rebuild.py::rebuild_semantic` and return an error step formatted by the now-public `format_asset_refresh_error`, so `retrieval.rebuild-semantic` on a vault without a provisioned model yields a structured conflict result instead of an internal error and traceback; observed through the CLI in Brain Lab.
- Cover the missing-model case in `tests/test_fresh_interpreter.py`.
