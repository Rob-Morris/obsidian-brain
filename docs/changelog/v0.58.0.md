# v0.58.0

**Summary:** Make `shaping.start` adaptive, auditable and status-aware

**Type:** Brain Core minor; portable skill layout and shaping contract extension

## Changed

- Make `src/brain-core/skills/shaping/references/` reconcile answers across current source state, stable decision/work IDs and append-only `Rn` transcript events instead of replaying historical dialogue.
- Add the consent-based four-Cs workflow in `references/review.md`, with accepted findings routed back through brainstorm, refine or discovery before completion.
- Compile taxonomy `Status behaviour` through `compile_router.py`; `preserve` keeps enduring discovery states while an optional completion status provides an approved exit from explicit `shaping`.
- Make `start_shaping_session.py` reject terminal preserved targets and continue the uniquely widest same-day transcript after canonical path/basename source-link deduplication.
- Flatten shaping, code-review and swarm-test sub-workflows under one public `SKILL.md` plus direct `references/*.md` files, and update `.claude/commands/swarm-test.md` to those paths.
- Align `cli/brain` and `cli/brain.cmd` to install Brain Core v0.58.0 while retaining `BRAIN_CLI_VERSION=2.1.0` because CLI dispatch is unchanged.

## Verification

- `tests/test_start_shaping.py` covers preserved status, terminal rejection, widest-source continuation and canonical source-link deduplication.
- `tests/test_shaping_skill_contract.py` and `tests/test_core_skill_portability.py` enforce adaptive workflow, review-consent and portable-reference contracts.
- `tests/test_compile_router.py`, `tests/test_bdd_compile_router.py` and `tests/application/test_shaping_start_owner.py` cover compiled and typed status behaviour.
