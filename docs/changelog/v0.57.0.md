# v0.57.0

**Summary:** Add ceiling-visible MCP discovery and Reader-default exact access leases

**Type:** Breaking Brain Core minor; coordinated CLI 2.1.0

## Changed

- Split `ProfileAuthority` into an immutable profile ceiling and the `defaults.access.initial_profile` active grant. Exact principal-scoped leases activate within-ceiling commands with absolute expiry and optional bounded uses.
- Add bootstrap-tier `access.status`, `access.request` and `access.reduce` application commands across MCP, CLI, direct script and typed Python. Active-grant denial returns a structural `access.request` next action before dynamic request resolution.
- Project `register_application_tools`, `brain.command-interface-header/1`, `command.list` and `command.describe` from the authenticated ceiling. Ordinary leases do not mutate `tools/list`; credential or ceiling changes continue to use proxy replacement and client re-discovery.
- Add CLI-only launcher command `brain access approve` for `external` elevation policy. It requires a separately supplied registered operator key whose profile covers every requested command and never exposes the approval command or secret through MCP.
- Restrict Reader-level `vault.read-file` to ordinary non-hidden vault files and explicit public Brain Core documentation trees. Private `.brain/`, `.brain/local/`, `.obsidian/`, `.brain-core/defaults`, `.brain-core/scripts` and symlink aliases into those namespaces are rejected.
- Expand the authoritative catalogue to 71 application commands and 60 MCP-eligible commands. Built-in profile ceilings are 26/48/61/70/71 application commands and 26/47/58/59/60 MCP tools.

## Upgrade

- `migrate_to_0_57_0.py` adds the three access controls only to exact shipped profile sets. Custom profiles retain only their explicit grants and fail closed.
- `BRAIN_INSTALL_REF` advances to `v0.57.0`; `BRAIN_CLI_VERSION` advances to `2.1.0` because the launcher gains `access.approve` and interactive trusted-key handling.
- MCP clients reconnect through proxy protocol 2 to receive the ceiling-specific catalogue. `brain.access-state/1` lease changes do not require reconnect.

## Verification

- `tests/application/test_access_grant_owners.py` covers persistence, expiry, use counts, discovery, ceiling enforcement and symlink refusal; `test_launcher_access_approval_owner.py` covers external approval.
- `tests/fixtures/command_interface_granular_mcp_projection_v1.json` captures supported Claude Code and Codex declarations; the full 60-tool catalogue remains below the 16,384-token release ceiling.
