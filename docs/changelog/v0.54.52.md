# v0.54.52

**Summary:** Compose launcher-owned discovery into the local command view

- Add authoritative launcher list and describe operations over the static
  launcher catalogue, sealed request/result types and already-bound provider
  state.
- Derive strict request/result schemas and resolver-checked minimal examples
  for every launcher command without importing the selected-Brain application.
- Add a presentation-only `_local_cli` boundary that composes application and
  launcher discovery while preserving both catalogue schemas, fingerprints,
  cursors and owned payloads.
- Reject cross-catalogue command collisions and stale launcher cursors, and
  keep the composed public grammar dormant until the coordinated CLI 2.0
  cutover.
