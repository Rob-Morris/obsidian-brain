# v0.53.0

**BREAKING — Rename shaping action and enforce session invariants**

- Replace the ambiguous `start-shaping` MCP action with `shape={target, mode}`. `shape` consistently means open or continue the source artefact's shaping activity; the skill-selected mode is required and the old MCP discriminator is no longer accepted.
- Introduce `start_shaping_session()` as the internal session-boundary primitive. It validates shapeability before mutation, preflights the transcript template, uses the canonical lifecycle status handler, reports precise changed paths, and preserves partial-apply repair context.
- Compile each complete taxonomy `## Shaping` section into flavour, bar, and completion-status metadata, validating both status values against the taxonomy's explicit lifecycle. A stable compiler error code gates the pre-compile migration, which carries inline, table, and prose lifecycle values into an authoritative Markdown table and verifies its post-condition before writing; malformed sibling taxonomies are reported without abandoning safe repairs.
- Preserve one same-day transcript per source artefact in `start_shaping_session()` by resolving reciprocal links with normal Obsidian full-path and unambiguous-basename semantics. Stale and non-reciprocal backlinks are ignored safely, same-title artefacts remain disambiguated rather than sharing transcripts, literal tildes in living titles are retained, and backlink-only writes refresh source modification metadata.
- Resolve the shaping-transcript folder, filename/date rule, frontmatter type, and template through the compiled taxonomy contract, including vault-specific overrides.
- Keep `start_shaping.py` as a compatibility launcher for direct script consumers; its legacy `title` input no longer changes transcript identity, and old `skill_type: Shaping` or custom labels derive the mode from the taxonomy instead of failing validation.
- Treat malformed non-scalar retrieval-index dates as missing metadata and surface missing files from `brain_outline` as errors rather than false empty outlines.
- Add an explicit `configure.py agent-skills` surface for Claude Code and Codex. It lazily reads and installs one ownership-marked `shaping` discovery adapter per selected client from `client-adapters/shaping/SKILL.md`; unrelated configure commands therefore remain usable if that optional template is unavailable. Each client operation contains filesystem-boundary errors independently, and incidental Finder metadata does not block safe management. The adapter resolves the active Brain and reads its version-matched shaping workflow at invocation time. Existing unmanaged skills are preserved unless `--replace` archives them first. `upgrade.py` reports a structured command when this stable adapter is introduced or changed, but never writes client-global skill directories implicitly or prompts for ordinary `skills/shaping/` workflow updates.
- Align the Brain version badge and `brain` installer pin with v0.53.0; CLI dispatch behaviour and `BRAIN_CLI_VERSION` are unchanged.
