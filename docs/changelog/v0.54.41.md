# v0.54.41

**Add fail-closed managed-runtime repair launcher ownership**

- Add the typed `_launcher.runtime` owner for `runtime.repair`, with a frozen
  empty request and bounded runtime/step result over trusted selected-Brain
  context.
- Reuse the bootstrap-tier runtime orchestrator directly without silently
  handing off into the managed interpreter.
- Add receipt-oriented `effect_outcome` metadata to runtime resolution so
  no-effect, committed, known-partial and unknown mutations remain distinct.
- Refuse to delete or replace a present unusable runtime without live-use proof,
  correcting the former path that could trust a stale sentinel after an
  incompatible probe.
- Receipt successful creation/synchronisation as one managed-runtime effect,
  retain completed dependency changes with failed verification as known partial
  and treat interrupted venv/pip mutations as non-retryable unknown outcomes.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.41; CLI
  and proxy protocol versions remain unchanged.
