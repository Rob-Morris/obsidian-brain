# v0.54.22

**Migrate typed artefact maintenance and link-fix owners**

- Add typed operator owners for `artefact.reparent-children`,
  `artefact.repair-frontmatter`, `artefact.repair-ownership`,
  `artefact.migrate-naming` and `links.fix`.
- Replace the legacy omitted/null child-reparent overload with explicit
  `source-parent`, `top-level` and named `parent` modes.
- Reuse the repair, naming, ownership and link semantic modules while keeping
  lock, authority, retry, dry-run and outcome policy in the application layer.
- Return bounded repair steps and notes without selected-vault or managed
  interpreter paths, and distinguish no-op, planned, changed and partial state.
- Split link preview from application through explicit `apply` intent, support
  scoped link filters only where meaningful, and report typed resolvable,
  ambiguous and unresolvable targets.
- Preserve structural naming-migration details and known-partial results while
  refusing hidden scope/options on zero-input maintenance commands.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.22;
  CLI and proxy protocol versions remain unchanged.
