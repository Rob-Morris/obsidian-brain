# v0.55.2 — Native Windows Bootloader Verification

**Verify native Windows bootloaders by platform semantics**

**Date:** 2026-08-11
**Type:** Brain Core patch release; coordinated CLI 2.0.1 patch

## Fixed

- Made `_distribution._verify_pair()` validate the `.cmd` bootloader identity on native Windows without requiring POSIX execute bits that Windows does not preserve.
- Restored `_distribution._validate_source()` enforcement that the actual `src/brain-core/VERSION` matches the requested distribution version.
- Kept POSIX `0755` verification unchanged for Unix-like CLI bootloaders.
