# v0.55.3 — Installed Windows CLI Distribution Root

**Resolve installed Windows CLI distribution roots**

**Date:** 2026-08-11
**Type:** Brain Core patch release; coordinated CLI 2.0.2 patch

## Fixed

- Made `cli/brain.cmd` establish its installed `lib\brain-cli\<version>` distribution before applying bundle or source-checkout overrides.
- Removed the ambiguous nested `else if exist ... if exist` grammar that could leave `DISTRIBUTION_ROOT` empty for installed Windows users.
- Preserved `BRAIN_CLI_BUNDLE` and source-checkout discovery precedence.
