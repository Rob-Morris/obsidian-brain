# v0.76.1

**Summary:** Keep scoped link checks bounded and MCP replies responsive

**Type:** Brain Core patch; link checking and MCP reliability

## Changed

Scoped link checks read only their approved public source, reuse one target index and analysis, and exclude generated runtime state. Private aliases are refused before opening and findings retain the observed source identity. Link-free and non-standard scoped sources return empty findings without indexing the vault.

MCP command execution uses a bounded serial worker so completed replies can be delivered during later work. Cancellation retains started-handler finalisation, and owned-outcome recovery accepts complete delivery metadata while retaining receipt validation.
