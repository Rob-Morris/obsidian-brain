# v0.67.0

**Summary:** BREAKING — Flatten temporal date folders and let sync carry conventions

**Type:** Breaking Brain Core minor; vault-structure change

Temporal artefacts no longer file into `yyyy-mm/` month folders. They sit flat
under their type root (`_Temporal/Logs/20260314-log.md`) or owner chain
(`_Temporal/Reports/project~brain/20260314-report~Title.md`); chronology comes
from the dated filename, which the naming rule's `date_source` still governs.
Decision and alternatives in `docs/architecture/decisions/dd-071-flat-temporal-filing.md`;
who owns definition updates in `dd-072-definition-convention-ownership.md`.

Migration: `migrate_to_0_67_0` runs on upgrade. It moves every file under a
`yyyy-mm` directory beneath `_Temporal/` up past that segment in one
preflighted move set, rewrites wikilinks vault-wide, prunes the vacated
folders, leaves `_Archive` untouched, and removes the path-keyed retrieval
caches so the post-upgrade repair rebuilds them. Preview it, and the
definition sync that follows, with `upgrade.py --dry-run`. An existing
destination stops the upgrade before any write. A month folder still holding
non-artefact content (for example `.DS_Store`) is left in place and named in
the migration's `warnings`; clear it with `repair.py empty_folders`.

## Changed

- `_common.resolve_folder(artefact, parent=None, router=None)` returns `{type root}/` or `{type root}/{owner chain}/` for temporal artefacts; the month computation and the `fields` parameter are gone. Every caller (`create.py`, `edit.py`, `check.py`, `start_shaping_session.py`, historical migrations including `migrate_to_0_29_0._target_folder`) follows, and `edit._temporal_owner_relocation_path` loses the dead date-parse fallback.
- `edit._temporal_owner_relocation_path` (was `_temporal_month_relocation_path`) relocates a temporal file only when `_finish_artefact` sees its `parent` change; the `created`-driven half of the old trigger is gone. Consequences: a body edit on a temporal file whose existing `parent` no longer resolves now succeeds and leaves the file in place (the `parent_contract` check still reports the broken parent) instead of failing before write; changing the parent to an unresolvable one still fails before write; and an ordinary edit no longer re-files a temporal file sitting in a stale folder — `parent_contract` reports it and the migration or a parent change moves it.
- `edit._plan_unarchive_entry` re-files a restored artefact through `resolve_folder` when it has no parent or its recorded parent no longer resolves in the router, instead of restoring the archive-relative path. Parentless restores land flat at the type root; `standards/archiving.md` records that archived layout is historical.
- `check.check_month_folders` and the `month_folders` check id are removed. `check.check_parent_contract` now reports an unparented temporal file in a subfolder as an implied owner or an orphan, exactly as it does for living files, so a hand-made legacy month folder is still detected. New `check.check_taxonomy_conventions` reports, as non-repairable `info` findings, installed taxonomies whose Naming folder still breaks a convention rule, pointing at definition sync (including the `artefact_sync_exclude` case).
- `compile_router` owns the convention machinery beside the taxonomy parser: `NAMING_SECTION_RE` (shared by parser and rewriter), `legacy_month_folder`, the `CONVENTION_RULES` table (rule label, classification scope, matcher — one temporal rule at this release), `match_convention_rule` and `rewrite_naming_folder`, which rewrites only the backticked folder token inside `## Naming` when it occurs exactly once. `naming_storage_root` no longer special-cases a literal `yyyy-mm` segment.
- `sync_definitions.py` gains a convention pass for unmanaged custom taxonomies: `discover_unmanaged_taxonomies` walks `_Config/Taxonomy/` (via `_common.TAXONOMY_DIR` and `classification_from_subdir`) minus every manifest, tracking and library-directory target (fail closed when a manifest cannot be parsed); `apply_convention_updates` rewrites exact matches, records `action: "convention"`, `rule`, `previous` and `folder` on the entry, preserves and warns ambiguous tokens, never writes a tracking entry, and is skipped for `--types` scoped syncs and under `artefact_sync: skip`. `format_sync_updated`/`format_sync_warning`/`format_sync_error` render entries for both `sync_definitions.py` and `upgrade.py`, whose real-run output now lists sync errors instead of dropping them.
- `_lifecycle.retrieval_assets.drop_path_keyed_retrieval_caches` removes the lexical index and embeddings sidecars in one place; the migration calls it before moving files so a failed run cannot leave a falsely fresh index behind.
- `shape_printable.py` and `shape_presentation.py` write to `_Temporal/Printables/` and `_Temporal/Presentations/` without a month segment.
- Artefact library, shipped standards (`naming-conventions.md`, `hub-pattern.md`, `shaping.md`, `extending/adding-temporal-type.md`, `extending/adding-living-type.md`, `archiving.md`), `guide.md`, the template vault (`_Config/Taxonomy/Temporal/*.md`, `.brain/tracking.json`, `vault-maintenance` skill assets) and repo docs (`docs/user/system-guide.md`, `workflows.md`, `template-library-guide.md`, `getting-started.md`) describe flat filing and the sync convention pass.
- `scripts/migrations/README.md` gains the definition-ownership section; `docs/architecture/decisions/README.md` indexes DD-071 and DD-072, and DD-009 is marked extended by both.
- Tests: `tests/test_migrate_to_0_67_0.py`, `tests/check/test_check_taxonomy_conventions.py`, `TestConventionUpdates` in `tests/test_sync_definitions.py`, unarchive normalisation tests in `tests/edit/test_edit_lifecycle.py`; the suites that encode temporal filing (check, edit, create, BDD features, shaping, search, listing, migrations, `tests/brain_test_support.py`, `tests/fixtures/inline_search_benchmark.json`, the command-vault seed) move to flat paths, while path-agnostic rename tests and historical-migration fixtures keep their month literals deliberately and the frozen v0.54.0 fixtures are untouched.
