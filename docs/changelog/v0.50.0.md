# v0.50.0

**Add recursive nested ownership migration and mutation safety**

- Add the v0.50.0 recursive owner-folder migration. It backfills safe missing `parent:` metadata from existing owner folders, validates parent chains and move sets before writes, moves living descendants into recursive owner paths, and preserves structured blocker/partial-apply diagnostics through direct CLI and `upgrade.py`.
- Make nested ownership mutations fail loud before writes when the compiled router/index, scanned parent references, and rendered owner paths disagree. MCP now surfaces stale-index and parent-chain failures as actionable errors instead of generic unexpected failures.
- Add cycle validation and shared move-set preflight for edit, convert, archive, and reparent flows, including duplicate/cyclic moves, destination collisions, symlink endpoints, broken destination parents, and vacated-destination semantics. Delete adds recursive descendant gates and partial-apply diagnostics without using move-set destination preflight.
- Add recursive delete/archive and reparent support for MCP surfaces. Descendant-bearing operations return `HAS_DESCENDANTS` until callers opt in to recursive mutation, and successful moves prune vacated owner folders.
- Introduce typed partial-apply errors for documented non-atomic mutation failures, preserving repair context at CLI, migration, and MCP boundaries.
- Align `cli/brain` install pin to `v0.50.0`; `BRAIN_CLI_VERSION` is unchanged because the CLI dispatch surface did not change.
