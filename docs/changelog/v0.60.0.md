# v0.60.0

**Summary:** BREAKING — Replace machine-shaped launcher commands with domain language

**Type:** Breaking Brain Core minor and Brain CLI major; launcher interface

## Changed

- Replace implementation-shaped launcher spellings with domain language:
  `brain migrate-legacy-installations`, `brain runtime remove-orphans`, and
  `brain registry remove-stale`.
- Preserve the direct `brain resolve` Brain-ID-to-vault-path lookup.
- Consolidate `brain runtime resolve` and `brain runtime resolve-runnable` into
  `brain runtime inspect`. The unified typed result reports the expected
  managed runtime, whether it exists, and the selected runnable Python path and
  source; an unavailable runnable is successful inspection state.
- Remove the duplicate `brain backfill` surface in favour of `brain register`.
  Lifecycle internals retain the lower-level helper where an installation
  workflow needs it.
- Collapse the redundant launcher noun in commands such as `brain doctor` and
  `brain upgrade`. Other domain nouns remain explicit.

The launcher catalogue contracts from 24 to 22 commands. These commands are
not MCP-eligible, so the MCP catalogue is unchanged. There are no compatibility
aliases. Brain CLI advances to 3.0.0 and is installed by the normal checked
upgrade pathway.

## Migration

| Before | After |
|---|---|
| `brain machine migrate-legacy` | `brain migrate-legacy-installations` |
| `brain machine prune-runtimes` | `brain runtime remove-orphans` |
| `brain backfill` | `brain register` |
| `brain prune` | `brain registry remove-stale` |
| `brain runtime resolve` / `brain runtime resolve-runnable` | `brain runtime inspect` |
| `brain brain doctor` / `brain brain upgrade` | `brain doctor` / `brain upgrade` |

## Verification

- Launcher catalogue, discovery, request projection and typed owner tests pin
  all new IDs and entry points and reject removed spellings.
- Runtime tests cover managed, launcher and unavailable selection state in the
  unified inspection payload.
- Registry and runtime mutation tests retain authority, provider, dry-run,
  effect and durable-receipt contracts after the renames.
- Native Unix and Windows bootloader tests pin CLI 3.0.0 and the v0.60.0
  installation ref.
