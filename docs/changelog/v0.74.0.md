# v0.74.0

**Summary:** Make exact-version installs reproducible without replacing shared CLIs

**Type:** Breaking Brain Core minor; release acquisition and CLI lifecycle contracts

## Changed

- Resolve remote installation and upgrade to one verified release snapshot, retaining commit/tree provenance and refusing changed retained acquisitions.
- Preserve a healthy machine-global CLI unless replacement is explicitly requested, and execute lifecycle policy from the selected source without mixing imported releases.
- Expose offline CLI component, distributed-with Core and earliest full-support Core metadata; the first supported Core baseline is 0.74.0.
- Keep verified-source failure recovery pinned to the original source and destination, with usable native PowerShell retry guidance on Windows.
- Preserve Unicode machine results through non-UTF-8 Windows pipes and certify the new release boundary with an explicit Brain Lab adapter.
- Observe Python launcher replacement at the same path instead of selecting a managed runtime from a stale cached version.
