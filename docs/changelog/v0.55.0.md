# v0.55.0 — Brain Command Architecture

**BREAKING — Release: Brain Command Architecture**

**Date:** 2026-08-11
**Type:** Breaking Brain Core minor release; coordinated CLI 2.0.0 and proxy 0.7.0 cutover

## Changed

- Replaced aggregate MCP tools with 78 catalogue-derived granular tools using canonical dotted `<noun>.<verb>` names, backed by one 86-command application catalogue.
- Replaced irregular CLI 1 commands with CLI 2's canonical `brain <noun> <verb>` grammar and strict JSON requests.
- Made `scripts/command.py <noun> <verb>` the one supported selected-Brain direct-script projection.
- Made sealed request/result types, `CommandApplication`, the application catalogue and the independent launcher catalogue authoritative across MCP, CLI, script and Python.
- Added structural `ok | partial | error` results, stable exit categories and durable outcome references so uncertain mutations are never blindly replayed.
- Activated fail-closed proxy protocol 2 and replacement-server compatibility checks before tool lookup.
- Added a checked multi-vault upgrade transaction that preflights the complete local registry, requires exact acknowledgement for affected Brains, replaces Brain Core and the versioned CLI distribution together, and proves rollback or retains recovery material.
- Migrated built-in and custom MCP profile allow-lists once to exact granular command names; removed runtime aggregate fallback.
- Removed the public aggregate MCP server implementation, public legacy operation scripts and compatibility command mappings.

## Compatibility

This is an intentional breaking cutover. Agents must discover the installed interface with `command.list` / `command.describe` or `brain command list` / `brain command describe`. Removed MCP 1.x names and CLI 1 aliases are not callable.

CLI 2 refuses application discovery against Brain Core older than 0.55.0 while retaining launcher-owned discovery and recovery. Upgrade all registered local Brains as one acknowledged cutover before relying on the new global CLI.

No release tag or package publication is implied by this repository entry; those actions remain separately authorised.
