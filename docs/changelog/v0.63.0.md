# v0.63.0

**Summary:** Modernise artefact definitions and Note naming

**Type:** Brain Core minor

## Changed

- Redefine Notes as evolving personal working knowledge, remove the flat one-concept model, and adopt stable human-readable `{Title}.md` filenames.
- Migrate legacy date-prefixed living Note filenames during upgrade, preflighting path and case-insensitive title collisions and updating matching wikilinks through the shared rename machinery. Include the complete link-rewrite surface in upgrade rollback snapshots.
- Align Wiki, Writing, Releases, Tasks, Journals, Research, Projects, Zettelkasten, lifecycle, and naming guidance with canonical ownership and current human-readable naming conventions.
- Extend the current Brain Lab compatibility adapter through the v0.63 release family so release validation and upgrade scenarios select the established command contract.
