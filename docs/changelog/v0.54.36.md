  `brain.unregister`, `brain.set-default`, `brain.clear-default` and
  `brain.prune`, with operator authority and explicit caller-filesystem

  plans still fail visibly.

  `prune_action` commits registry rows before default-pointer cleanup fails;
  unexpected failures remain receipt-backed, non-retryable unknown outcomes.

  2.0 cutover; the current `cli/brain` dispatch grammar remains unchanged.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.36;
