# v0.54.6

**Migrate portable skill, style, and plugin document owners**

- Add separate typed read and list owners for skills, styles and plugins, each
  with its own request, exact result payload, executor, resolver and catalogue
  identity.
- Put exact named-document resolution, content loading and query filtering in
  adapter-free `_portable/named_documents.py`; legacy `read.py` and
  `list_artefacts.py` delegate to the same lower semantics.
- Keep skill provenance explicit through bounded `source` fields while style
  and plugin results expose only their honest name/content contracts.
- Sort new application list results deterministically, reject empty or extra
  intent, and map missing resources or router state to structural no-effect
  errors.
- Add installed command-vault coverage for filtered skill discovery, style
  content, empty plugin state and a fresh-clone installed-plugin round trip.
- Keep public MCP, CLI and direct-script grammar unchanged; the migration is
  internal until the coordinated breaking cutover.
- Align `src/brain-core/VERSION`, the README badge, and `BRAIN_INSTALL_REF`
  with v0.54.6. `BRAIN_CLI_VERSION` and `PROXY_VERSION` remain unchanged
  because their public behaviour and protocols did not change.
