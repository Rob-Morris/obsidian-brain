**Migrate rollback-safe workspace-registry repair ownership**

- Add the typed operator command `workspace.repair-registry` for the selected
  Brain's linked-workspace registry.
- Extract portable inspection, normalisation and malformed-copy preservation so
  the typed command and existing repair orchestrator share one semantic owner.

  avoiding the former missing-registry window whenever rollback succeeds.
- Report a failed restoration as known partial application with the preserved
  backup path, rather than an unqualified or retryable failure.
- Return bounded status, reason, entry count and vault-relative backup identity
  under application-owned authority, locking and receipt policy.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.28;
  CLI and proxy protocol versions remain unchanged.
