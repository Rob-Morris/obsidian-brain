# v0.54.48

**Summary:** Add the direct selected-Brain command projection

- Add `scripts/command.py <noun> <verb>` as the staged direct-script projection
  over the authoritative application catalogue and resolver.
- Accept one strict JSON request object inline or from stdin, then resolve it to
  the same sealed request used by later CLI and MCP projections.
- Emit canonical JSON alone on stdout in JSON mode, concise human output on the
  correct stream otherwise, and preserve the shared exit categories 0–4.
- Resolve selected-Brain, profile, tier, workspace and provider state without
  silent runtime hand-off, dependency provisioning, or aggregate-name aliases.
- Keep default discovery probe-free; explicit refresh probes each distinct
  provider once through the bounded capability refresher.
- Reuse one catalogue/resolver assembly per invocation and validate the direct
  provider inventory against every catalogue declaration.
- Permit concrete adapters to extend config tool-name validation from their
  authoritative projected catalogue without coupling config back to it.
- Keep the new projection undispatched by the global CLI and current MCP until
  the coordinated breaking cutover.
