# v0.53.2

**Keep replaced skill backups outside client discovery roots**

- Move `configure.py agent-skills --replace` archives to `~/.<client>/.brain-skill-backups/shaping.pre-brain-adapter[-N]` so Claude Code and Codex cannot rediscover the retired workflow as duplicate skills.
- Keep `_archive_and_install()` on the client filesystem for atomic `os.replace`, while `_refuse_symlinked_destination()` also rejects a symlinked `.brain-skill-backups` root.
- Extend `tests/test_agent_skills.py` to verify the new archive boundary, numbered backups, preserved nested sub-skills, and fail-closed symlink handling.
- Align `src/brain-core/VERSION`, the README badge, `BRAIN_INSTALL_REF`, and template-vault tracking metadata with v0.53.2; `BRAIN_CLI_VERSION` remains unchanged because CLI dispatch behaviour did not change.
