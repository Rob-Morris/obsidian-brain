# v0.54.20

**Migrate typed artefact lifecycle mutation owners**

- Add distinct `artefact.reparent`, `artefact.set-status`, `artefact.set-key`
  and `artefact.set-naming-field` application commands with concrete typed
  requests and structural lifecycle results.
- Require callers to include `parent` when reparenting while accepting an
  explicit null value to clear ownership, so omission can never silently move
  an artefact out of its owner projection.
- Preserve `edit.update_lifecycle_field` as the single semantic authority for
  status validation, protected metadata, naming preflight, derived moves,
  ownership tags, links and indexes.
- Enforce contributor authority, receipt-required retry, mutation locking,
  honest unknown outcomes and explicit dry-run refusal through the shared
  application boundary.
- Cover owner moves, terminal status projection, key changes, naming-driven
  renames, transport intent, discovery metadata and post-commit uncertainty
  against disposable installed Brain vaults.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.20;
  CLI and proxy protocol versions remain unchanged.
