# v0.55.1 — Supported MCP Runtime Major

**Bound the managed runtime to the supported MCP major**

**Date:** 2026-08-11
**Type:** Brain Core patch release

## Fixed

- Constrained the managed runtime to MCP 1.x, whose FastMCP API is the interface implemented by this Brain release.
- Made contributor setup and the native Windows smoke workflow consume the shipped runtime requirements instead of independently restating the MCP dependency.
- Prevented a fresh install from resolving incompatible MCP 2.x packages after their upstream release.
