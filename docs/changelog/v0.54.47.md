# v0.54.47

**Summary:** Compose trusted local command context and durable receipts

- Add the concrete local composition boundary outside `_application`, keeping
  selected-Brain, profile, tier, provider, capability and workspace discovery
  out of transport-neutral execution.
- Enforce granular projected command names directly from each authenticated
  profile allow-list without aggregate-command fallbacks.
- Add a cross-process file receipt store for effect-bearing command outcomes
  under the selected Brain's fixed machine-local state directory.
- Hash invocation identifiers into fixed filenames and persist only command
  identity, outcome state, time and compact committed-effect references.
- Reject symlinked or corrupt receipt storage, preserve immutable records, and
  enforce bounded count and age retention.
- Keep read-only and other proven no-effect results out of durable storage.
