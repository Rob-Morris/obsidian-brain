# v0.51.0

**Release: Vault Tooling Maturity - Pass 2**

- Close the final safety gaps for Vault Tooling Maturity - Pass 2.
- Create and conversion paths now file parented temporal artefacts under their living owner chain before the `yyyy-mm` folder, using `_common.resolve_folder(...)`, `create.py`, and `edit.py` so hub-scoped temporal work does not collapse into the global temporal namespace.
- Direct mutation scripts now align with MCP stale-state policy: `create.py`, `edit.py`, `rename.py`, and `fix_links.py` refuse stale or unreadable compiled router state before writing or scanning for fixes.
- `edit.py` now wraps post-metadata move failures such as terminal-status relocation or date-folder relocation in `PartialApplyError` with the written metadata path and underlying move cause.
- `_common/_wikilinks.py`, `rename.py`, `fix_links.py`, and `check.py` now share table-aware wikilink behaviour: rewrites inside markdown table rows drop unsafe aliases, and `check.py` reports existing table-row aliased wikilinks as `table_wikilink_alias` warnings.
- Update `docs/functional/scripts.md`, `docs/functional/mcp-tools.md`, `docs/user/user-reference.md`, `docs/architecture/security.md`, and `src/brain-core/guide.md` for the release-closure contracts.
- Add the milestone release note at `docs/changelog/releases/v0.51.0-vault-tooling-maturity-pass-2.md`.
- Align `cli/brain` install pin to `v0.51.0`; `BRAIN_CLI_VERSION` is unchanged because the shell dispatch surface did not change.
