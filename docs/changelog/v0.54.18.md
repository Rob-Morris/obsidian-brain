# v0.54.18

**Migrate typed artefact document mutation owners**

- Add distinct `artefact.edit`, `artefact.append`, `artefact.prepend`,
  `artefact.delete-section` and `artefact.replace-text` application owners.
- Model structural scope, duplicate-target occurrence and ancestor selection as
  bounded typed values shared by document mutations.
- Accept body content only through inline or staged sources and preserve
  frontmatter-only edits without exposing caller-owned paths.
- Keep lifecycle-owned frontmatter behind its dedicated commands and retain
  `edit.py` as the body, metadata, move and link-reconciliation authority.
- Return line counts, resolved structural targets, replacement counts,
  wikilink findings and fixes through one structural result contract.
- Consume staged content only after commit, retain it on failed edits, and
  report unexpected post-commit failures through invocation outcomes.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.18;
  CLI and proxy protocol versions remain unchanged.
