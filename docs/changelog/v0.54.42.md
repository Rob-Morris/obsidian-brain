- Add frozen typed `McpConfigureRequest` and `McpRepairRequest` launcher owners with closed
  client, scope and action grammar; trusted selected-Brain, caller-directory and
  home-directory context; bounded file plans; and exact committed effects.

  to strictly preflight JSON,
  TOML, Markdown and init-state inputs, detects concurrent changes, restores
  written files and created directories on failure, and reports any surviving
  rollback paths as a known-partial receipt.

  their own command owners. MCP configure/repair fail closed when their runtime
  or binding prerequisite is unhealthy, while exact recorded removal remains
  available without either prerequisite.
- Keep the existing public v1 `configure.py`, `repair.py` and MCP projections
  unchanged until the coordinated breaking cutover. `BRAIN_CLI_VERSION` and
  `PROXY_VERSION` remain unchanged because neither public adapter changes here.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.42; add
  `tests/application/test_launcher_mcp_owners.py` coverage for preflight,
  rollback, partial receipts, close-safe removal and repair convergence.
