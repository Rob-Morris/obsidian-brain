# v0.55.8 — MCP SDK 2 Server Boundary

**Admit MCP SDK 2 and port the server adapter**

**Date:** 2026-08-12
**Type:** Brain Core patch release

## Changed

- Pinned the managed runtime to the reviewed official Python `mcp==2.0.0`
  release and recorded its exact cross-platform graph, licences, provenance,
  vulnerability audit, trust-store behaviour and non-exporting telemetry policy.
- Replaced the removed FastMCP 1.x integration with `MCPServer`, keeping all SDK
  specifics within the MCP transport boundary and preserving the authoritative
  application catalogue, strict schemas, resolver and result envelopes.
- Ported the proxy protocol gate to the SDK 2 method-handler API without moving
  its denial boundary: incompatible proxies still fail before tool lookup.
- Updated contract, parity, metadata and Windows smoke tests for SDK 2's Python
  field names, while retaining camel-case MCP wire fields.
- Verified current SDK stdio operation and explicit 2025-06-18 initialise,
  tool-list and call compatibility.

`BRAIN_INSTALL_REF` moves to `v0.55.8`; CLI dispatch behaviour and
`BRAIN_CLI_VERSION` remain unchanged.
