**Type:** Patch; contributor promotion workflow

- Add promotion.py recover plan, stage, status, apply and abort for exceptional direct-main divergence, preserving queued release notes and dev work through immutable Git plans and atomic, owned ref updates.
- Separate Git, candidate, lifecycle and recovery responsibilities under src/scripts/_promotion/; harden canary receipts and staged hooks, and document serial development checks versus candidate-time certification in docs/CONTRIBUTING.md.
- Exercise recovery, interruption, competing operations, private suffix adoption and workflow routing in tests/test_promotion_recovery_plan.py, tests/test_promotion_recovery_workflow.py, tests/test_promotion_recovery_integration.py and tests/test_promotion_workflows.py.
- Make repository hook fixtures independent of the host Git default branch and verify the policy under both main and master defaults.
