# v0.54.46

**Summary:** Add the shared dynamic application adapter boundary

- Add one `ApplicationAdapter` that proves catalogue/resolver identity parity,
  resolves transport payloads into sealed requests and invokes only through
  `CommandApplication` with caller-composed trusted context.
- Keep unknown commands, malformed payloads and identity smuggling as explicit
  adapter request failures before executor entry or effects.
- Project every semantic result once into canonical structured content, compact
  JSON and concise text while preserving the original typed result branch.
- Define exact shared presentation categories: ok `0`, partial `1`,
  request/domain failure `2`, authority/capability unavailable `3`, and
  infrastructure/unknown outcome `4`; parser failures use `2`.
- Make MCP error signaling structural: both `partial` and `error` project as
  errors, while `ok` remains non-error.
- Keep context composition and transport presentation outside `_application`;
  public adapters remain unchanged until the coordinated cutover.
