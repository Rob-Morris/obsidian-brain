# v0.52.0

**Make Brain tooling explicit, retry-safe, and metadata-authoritative**

- Reject handler-owned `parent`, `key`, `status`, and naming-field changes in generic `brain_edit`; add explicit MCP and CLI lifecycle commands that apply their derived moves, tags, timestamps, descendants, and wikilinks.
- Treat valid lifecycle metadata as authoritative. Doctor reports parent projection drift and `repair ownership` provides locked preview/apply recovery without inferring missing metadata from folders.
- Add retry-safe `brain_stage` body handles, a shared bounded cross-process mutation lock, exact-text replacement, structural outlines, structured read-only checks, and recursive unarchive symmetry.
- Make list creation/modified filters honest, reject unknown types, add stable cursor pagination, and return structured list/search/create/edit results.
- Replace flat create/edit parameter cross-products with resource, content, subject, and operation-discriminated MCP requests; add operator-only guarded type, trigger, and plugin definition workflows with optimistic replacement checks.
- Replace the mixed-permission `brain_process` MCP tool with read-only `brain_classify`/`brain_resolve` and mutating `brain_ingest`; make `brain_action` a genuinely discriminated request and rename its aggregate operation to `reparent-children`.
- Expand the strict Brain CLI with `outline`, `list`, `search`, `stage`, and lifecycle commands; bump the CLI surface to `1.1.0` and align the install pin to `v0.52.0`.
- Harden the new workflows after design review: centralise naming-driver discovery, batch ownership-repair reference scans, lazily build mutation-time link indexes, report uninspected recursive-unarchive candidates, and make staging quotas and handle consumption atomic across MCP and CLI processes.
- Complete the second hardening pass: preflight the full candidate naming state before lifecycle writes, enforce active-rule placeholder regexes while rendering, compile legacy simple-form placeholders into guarded field contracts, preserve historical `{slug}` patterns, normalise mutation-lock contention across MCP and CLI, make every `brain_list` branch return the same structured page envelope, and single-source authored configuration paths used by definition and compiler workflows.
