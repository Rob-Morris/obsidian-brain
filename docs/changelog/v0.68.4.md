# v0.68.4

**Summary:** Keep artefact caches coherent and router recovery actionable

**Type:** Brain Core patch; cache coherence and recovery

## Changed

Artefact creation and lifecycle moves could leave derived caches pointing at old paths, blocking later writes and hiding changes from other sessions. Application-owned creation and transitions now reconcile router and lexical state before completion, using incremental lexical updates for in-place changes and reporting committed content honestly if maintenance fails.

Router checks, repair and write admission share authoritative validation. Repairs verify their postcondition, while stale-cache and partial-maintenance failures carry precise recovery actions. Runtime status labels recorded warm-up progress and directs callers to a current router check, so past readiness cannot be mistaken for present cache health.
