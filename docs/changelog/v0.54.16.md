# v0.54.16

**Add create-only typed template creation ownership**

- Add a granular `template.create` request, result, resolver and catalogue
  owner under contributor authority.
- Reuse the immutable inline/staged content variants while rejecting separate
  frontmatter; templates remain full markdown documents with their frontmatter
  embedded in the content.
- Enforce true create semantics at the new application owner: an existing
  template returns a no-effect conflict and is never overwritten.
- Keep legacy aggregate template overwrite behavior unchanged until the
  coordinated public cutover, avoiding a mixed unreleased/released grammar.
- Preserve type-linked template path resolution and full-document validation
  through `create.py`, with staged-handle cleanup only after commit.
- Cover absent-template success, existing-content preservation, staged-handle
  retention, invalid documents, strict transport and post-commit uncertainty.
- Align `src/brain-core/VERSION`, the README badge, and `BRAIN_INSTALL_REF`
  with v0.54.16. `BRAIN_CLI_VERSION` and `PROXY_VERSION` remain unchanged
  because their dispatch and protocols did not change.
