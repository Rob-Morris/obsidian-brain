# v0.54.30

**Migrate safe managed content ingestion ownership**

- Add managed contributor command `content.ingest` with inline/staged content,
  optional exact type/title hints and explicit classification mode.
- Return typed classification, resolution, decision and create/update outcomes;
  consume staged content only after a committed mutation.
- Require a fresh router and lexical index while treating semantic retrieval as
  an optional provider, except when embedding mode explicitly requires it.
- Correct duplicate resolution so unnormalised BM25 scores remain advisory and
  cannot silently authorise an update; exact filenames and high-confidence
  semantic cosine matches retain update authority.
- Honour the existing public ingest `mode` field instead of silently ignoring
  it, while preserving receipt-backed uncertain post-commit outcomes.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.30;
  CLI and proxy protocol versions remain unchanged.
