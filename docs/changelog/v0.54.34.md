# v0.54.34

**Migrate trusted caller-local workspace mutation command owners**

- Add canonical `workspace.bind`, `workspace.configure-bootstrap`,
  `workspace.register`, `workspace.setup`, `workspace.unregister` and
  `workspace.update-metadata` application owners.
- Take the target workspace only from trusted invocation context backed by an
  available `caller_filesystem` provider; command payloads cannot supply host
  filesystem paths.
- Keep the caller-local commands bootstrap-capable and explicitly ineligible
  for MCP while retaining CLI, direct-script and Python projection eligibility.
- Preserve the existing binding, bootstrap, registry, setup and metadata
  semantic owners behind strict typed requests, mutation locks, dry-run plans,
  receipts and known-partial effect reporting.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.34;
  CLI and proxy protocol versions remain unchanged.
