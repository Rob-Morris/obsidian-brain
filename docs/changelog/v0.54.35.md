- Add a stdlib-only `cli/_launcher/` invocation boundary with trusted launcher
  context, authority/provider preflight, structural `brain.command-result/1`
  variants and outcome receipts independent of selected-Brain `_application`.
- Implement typed owners for `brain.get-default`, `brain.list`, `brain.resolve`,
  `brain.version`, `runtime.resolve` and `runtime.resolve-runnable`.
- Preserve the existing machine registry and managed-runtime path semantics
  behind strict requests and nested typed outputs; distinguish absence,
  expected conflicts and privacy-bounded internal failures.
- Correct the runtime owner references in the launcher catalogue so they point
  to managed-runtime resolution rather than the unrelated Brain-target resolver.
- Keep the internal launcher work dormant until the coordinated CLI 2.0
  cutover; the current public dispatch grammar remains unchanged.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.35;
  CLI and proxy protocol versions remain unchanged.
