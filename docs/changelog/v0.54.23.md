# v0.54.23

**Migrate typed plugin and trigger definition owners**

- Add distinct operator commands for `plugin.create`, `plugin.replace`,
  `trigger.create`, `trigger.replace` and `trigger.delete`.
- Accept plugin definitions through inline or staged content only, derive the
  installed plugin path from a validated name and consume staged bodies only
  after the definition commit succeeds.
- Require an optimistic SHA-256 precondition for plugin replacement and exact
  current condition/target intent for trigger replacement and deletion.
- Reuse `define.py` for plugin-document normalisation and router-entry mutation
  while the application layer owns authority, locking, receipts, dry-run and
  outcome classification.
- Return bounded definition identities and hashes without caller-file,
  interpreter or selected-vault paths; unexpected post-commit failures remain
  explicitly outcome-unknown.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.23;
  CLI and proxy protocol versions remain unchanged.
