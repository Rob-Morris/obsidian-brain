# v0.62.16

**Summary:** Report live runtime memory footprint in brain doctor

**Type:** Brain Core patch

## Changed

- Add `_machine/process_footprint.py`: `measure_footprint_bytes` reads the physical footprint of a live runtime process from macOS `footprint` (`phys_footprint`) or Linux `/proc/<pid>/status` (VmRSS + VmSwap), because resident set size understates compressed or swapped servers by two orders of magnitude.
- Annotate every live runtime process with `footprint_bytes` in `inspect_machine_runtime_state` and add an advisory `memory` section: total across live processes, processes over `PROCESS_FOOTPRINT_WARN_BYTES` (512 MB) and whether the total exceeds `TOTAL_FOOTPRINT_WARN_BYTES` (2 GB); `healthy` and `tidy` are unchanged.
- Render a `memory:` line and per-process warnings in `doctor_machine.render_human_lines`, so a session server that has grown heavy surfaces as a Brain signal rather than as another program being killed for memory.
- Cover parsing, platform dispatch and the summary in `tests/test_process_footprint.py` and `tests/test_machine.py`.
