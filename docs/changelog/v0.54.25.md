# v0.54.25

**Migrate typed artefact-library install and sync owners**

- Add distinct operator commands for singular `type.install` and `type.sync`
  intents while retaining `type.status` as their read-only discovery surface.
- Require explicit install of an uninstalled library type and reject accidental
  install-through-sync or sync-through-install requests.
- Preserve local customisation by default and expose `force` only on sync;
  correct the shared semantic owner so force now also replaces local-only drift
  as its existing documentation promises.
- Return typed per-role updates and skips with bounded relative targets, plus
  structural conflict, partial and unknown-outcome handling.
- Reuse `sync_definitions.py` for library discovery, tracking, comparison and
  writes while the application layer owns explicit intent, authority and lock.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.25;
  CLI and proxy protocol versions remain unchanged.
