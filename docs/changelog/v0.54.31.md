# v0.54.31

**Migrate managed semantic retrieval command owners**

- Add distinct managed operator commands for `retrieval.enable`,
  `retrieval.repair-semantic` and `retrieval.rebuild-semantic`.
- Require the `semantic_runtime` provider and preserve stable command identity
  when the managed tier or provider is unavailable.
- Move semantic opt-in lifecycle semantics out of the `configure.py` adapter
  while retaining its existing public behaviour during migration.
- Return typed dry-run, no-op, changed and partial results with receipt-backed
  effects; a provision failure after flag mutation no longer claims no effect.
- Keep unconditional semantic rebuild separate from health-based repair and
  force router, lexical-index and embedding-sidecar convergence.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.31;
  CLI and proxy protocol versions remain unchanged.
