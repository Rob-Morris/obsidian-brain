# v0.76.0

**Summary:** Deliver compact byte pages through opaque result continuations

**Type:** Breaking Brain Core minor; compact invocation-result delivery contract

## Changed

- Return text once in stable content fields with byte-based paging by default and an explicit line mode, preserving bounded UTF-8 output and explicit caller limits.
- Use opaque stateless continuation tokens across CLI and MCP while retaining independent result ownership, disclosure and coordinate validation.
- Consolidate bootstrap and document paging, preserve source outcomes, and report selected and outside-page boundaries accurately.
- Cache canonical page layouts and expose consistent navigation and recovery guidance without repeating source execution.
- Write pytest failure diagnostics immediately to a local log while preserving quiet console output.
- Provide an explicit Brain Lab compatibility adapter and CLI support baseline for Core 0.76 releases.
