# v0.62.18

**Summary:** Resolve NumPy after provisioning and type the doctor memory report

**Type:** Brain Core patch

## Changed

- Resolve NumPy on first use in `_semantic/assets.py::_require_numpy` instead of at import, and call `importlib.invalidate_caches()` after `sync_runtime_packages`; a first `retrieval.enable` in a fresh runtime previously installed the packages and then failed the asset refresh with "numpy is not installed" because the module had cached its absence. Reproduced in Brain Lab on Ubuntu 24.04 arm64.
- Add `DoctorMemoryStatus` and `DoctorHeavyProcess` to the launcher `brain.doctor` payload in `cli/_launcher/doctor.py` (`machine.memory`), so the advisory footprint report reaches the typed CLI and JSON surface rather than only the script renderer; CLI 3.1.6.
- Cover both in `tests/test_build_index.py` (NumPy resolved after a failed first import) and `tests/application/test_launcher_diagnostic_owners.py` (memory projection).
