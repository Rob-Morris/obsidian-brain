# v0.68.7

**Summary:** Reproduce locked dependencies and keep live MCP runtimes coherent

**Type:** Backward-compatible patch; dependency reproducibility

## Changed

- Install complete locked base, contributor and optional semantic dependency sets without resolving additional packages.
- Rotate managed runtimes when either shipped dependency export changes; verify exact versions during provisioning and explicit repair while retaining a healthy-startup fast path.
- Correct runtime repair requirements lookup and add offline dependency drift checks plus native dependency-certification CI.
- Preserve `--no-sync-deps` through MCP, retrieval and warm-up follow-on phases; retain actionable subprocess diagnostics and report repaired shared runtimes as changes.
- Treat the managed Python environment as part of a live MCP transport's identity: unchanged-runtime Core upgrades still refresh seamlessly, while dependency-runtime changes drain in-flight work, refuse new application calls without effects, and clearly require MCP restart.
- Report loaded and required runtime paths through proxy status, and let the explicit POSIX proxy handoff restart into the newly resolved managed runtime with fresh exceptional consent.
- Advance the private proxy protocol to `5` so pre-upgrade proxies fail closed with the existing `proxy_restart_required` result instead of dispatching updated Core commands through a stale environment.
