# v0.54.27

**Migrate typed lexical-index repair and rebuild owners**

- Add distinct operator commands for idempotent `retrieval.repair-lexical` and
  unconditional `retrieval.rebuild-lexical` intent.
- Extract portable lexical-index maintenance so typed commands and the existing
  repair orchestrator share cache inspection, construction and persistence.
- Invalidate semantic sidecars after a lexical rebuild so embedding-backed
  retrieval cannot silently serve a different document set.
- Return bounded document and term counts, cache reason and removed sidecars
  without exposing the selected vault or interpreter.
- Preserve known no-effect source/persistence failures and receipt-backed
  unknown outcomes after lexical persistence.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.27;
  CLI and proxy protocol versions remain unchanged.
