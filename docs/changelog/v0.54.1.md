# v0.54.1

**Establish typed `_application` command invocation contracts**

- Add the stdlib-only `scripts/_application/` package with typed request
  identity, trusted `InvocationContext`, ordered dependency tiers, orthogonal
  locality/provider state, and structural `brain.command-result/1` values.
- Make `CommandApplication.invoke` enforce catalogue identity, authority and
  capability checks before executor entry, validate typed results, and map
  unexpected failures to stable `internal_error` or non-retryable
  `command_outcome_unknown` results without exposing tracebacks.
- Define typed `OutcomeReceipt`, `OutcomeReference`, and `CommittedEffect`
  values so successful, partial, no-effect, and unknown outcomes cannot be
  represented interchangeably.
- Add `tests/application/` coverage for import closure, runtime/provider
  absence, request identity, result invariants, authority-before-effects,
  capability degradation, receipt failures, and catalogue fingerprints.
- Keep existing MCP, CLI and direct-script grammar unchanged in v0.54.1. The
  new package is the internal foundation for the coordinated command-interface
  cutover; no compatibility translator or mixed public surface is introduced.
- Align `src/brain-core/VERSION`, the README badge, and `BRAIN_INSTALL_REF`
  with v0.54.1. `BRAIN_CLI_VERSION` and `PROXY_VERSION` remain unchanged
  because their behaviour and protocols did not change.
