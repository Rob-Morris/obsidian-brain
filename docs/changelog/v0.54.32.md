# v0.54.32

**Migrate managed document rendering owners**

- Add separate `shaping.render-printable` and
  `shaping.render-presentation` contributor commands.
- Require the managed `document_renderer` provider while keeping both commands
  visible through stable capability-unavailable results.
- Preserve the distinct Pandoc/PDF-engine and Marp/preview request contracts
  instead of projecting a cross-product of invalid fields.
- Validate source paths before dry-run or rendering and return structural
  planned, complete, partial and no-effect results.
- Record markdown, PDF and preview-process effects independently so a renderer
  failure after artefact creation remains a known partial outcome.
- Align Brain Core, the README badge and `BRAIN_INSTALL_REF` at v0.54.32;
  CLI and proxy protocol versions remain unchanged.
