# v0.54.57

**Summary:** Stage explicit local command discovery grammar

- Add non-exiting `brain command list` and `brain command describe` parsing
  without activating the public v1 shell dispatcher.
- Make `--owner application|launcher|all` explicit and default local discovery
  to the honest composed view.
- Project list filters separately into selected-Brain request data and
  launcher-owned manifest filters instead of inventing shared semantics.
- Keep refresh selected-Brain-owned while launcher discovery remains a static,
  already-known manifest view.
- Validate application arguments through the canonical request resolver and
  launcher arguments through launcher discovery in focused tests.
- Assign all native grammar failures the stable request/parser exit category 2
  without allowing `argparse` to terminate the host process.
