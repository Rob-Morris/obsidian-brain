# v0.54.8

**Migrate exact vault-file and archived-artefact owners**

- Add distinct typed `vault.read-file`, `artefact.read-archived` and
  `artefact.list-archived` owners with strict request decoding, bounded result
  payloads and separate catalogue identities.
- Make `vault.read-file` accept only an exact vault-relative path and reject
  archive paths; archived artefacts have an explicit read owner rather than a
  hidden read mode.
- Preserve both the current top-level `_Archive` layout and legacy per-type
  archive discovery behind one adapter-free portable implementation.
- Reject vault escapes before file access and preserve existing legacy MCP and
  direct-script archive behaviour while those adapters delegate to the shared
  implementation.
- Add application, path-containment, archive-boundary, transport and legacy
  parity regressions.
- Keep the wider public MCP, CLI and direct-script grammar unchanged until the
  coordinated breaking cutover.
- Align `src/brain-core/VERSION`, the README badge, and `BRAIN_INSTALL_REF`
  with v0.54.8. `BRAIN_CLI_VERSION` and `PROXY_VERSION` remain unchanged
  because their dispatch and protocols did not change.
