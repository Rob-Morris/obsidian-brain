# v0.54.12

**Migrate typed managed `session.start` ownership**

- Add a real `session.start` request, executor and catalogue entry with managed
  dependency tier, reader authority, safe retry and derived-cache-write effect.
- Replace the open bootstrap dictionary at the application boundary with a
  fully typed `SessionStartPayload` covering core docs, rules, triggers, type
  summaries, environment, resource indexes, config and workspace context.
- Extend trusted `InvocationContext` with an optional absolute `workspace_dir`;
  workspace identity is composed by adapters rather than read from caller
  command fields or rediscovered from process environment.
- Remove the legacy no-op `context` request field from the canonical command;
  unsupported context scoping is not advertised as a semantic capability.
- Derive optional Obsidian CLI state from the bounded capability snapshot
  without probing during command execution.
- Preserve the canonical `session.py` model and `.brain/local/session.md`
  renderer as the single bootstrap content owner.
- Cover typed bootstrap content, trusted workspace context, catalogue metadata,
  mirror refresh and strict transport in
  `tests/application/test_session_start_owner.py`.
- Align `src/brain-core/VERSION`, the README badge, and `BRAIN_INSTALL_REF`
  with v0.54.12. `BRAIN_CLI_VERSION` and `PROXY_VERSION` remain unchanged
  because their dispatch and protocols did not change.
