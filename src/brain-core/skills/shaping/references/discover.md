# Discover

Use discover for **exploratory** shaping: developing understanding, capturing a
topic, or following useful threads without a bounded decision agenda.

## Discovery loop

1. Read the session plan and current artefact or in-session draft. Keep the
   stated purpose and completion bar in view while respecting the user’s desired
   scope.
2. Follow the user’s energy: deepen a thread when it remains valuable and
   broaden when adjacent context would improve the artefact more.
3. Incorporate each answer into the artefact or in-session draft and related
   in-scope material.
   Maintain a lightweight thread map only if the selected decision/work record
   is useful for preventing stale prompts or preserving deferred context.
4. Use bounded verification for time-sensitive or material factual claims when
   it fits the artefact’s purpose. Preserve uncertainty when verification is
   outside the present scope.
5. Record material reframing, scope changes, and durable deferrals through the
   storage selected in the session plan. Keep current understanding in the
   artefact rather than making the transcript the only usable record.

## Stopping and completion

The user may stop an exploratory pass whenever it is useful to do so. Assess the
artefact against the agreed bar for the intended current scope: it need not cover
every possible thread, and acknowledged uncertainty can be complete when it is
faithful to the purpose.

At a candidate stopping point, recommend the optional four-Cs review in
[review.md](review.md). Preserve any environment-specific lifecycle behaviour
only when the session plan selected that environment for the artefact.

## Watch for

- Turning useful exploration into a fixed questionnaire
- Treating acknowledged uncertainty as a defect by default
- Rewriting a bounded historical record as though it were a current-state document
- Losing useful deferred threads because the artefact contains no durable cue
