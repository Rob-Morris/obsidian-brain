# Refine

Use refine for a formed **convergent** artefact. Work through the live decision
and agent-work agenda until the agreed completion bar is met.

## Establish the agenda

Read the artefact or in-session draft and the selected decision/work record or
in-session agenda. Use the artefact or draft as the source of current content;
a transcript explains provenance but does not replace it. Create a small
current-state structure only where the selected record lacks an equivalent one:

- pending user decisions;
- pending agent work;
- resolved or superseded outcomes when a durable record is useful.

Classify each item before asking about it:

- **User decision:** genuinely viable outcomes remain and user judgement is the
  missing input.
- **Agent work:** bounded inspection, research, synthesis, or verification can
  reduce uncertainty without a preference decision.
- **Resolved or superseded:** keep any useful history, but remove it from the
  active agenda.

## Refinement loop

1. Choose the next action by dependency leverage, material impact,
   irreversibility, and useful user momentum.
2. Complete bounded agent work when it could collapse a decision. Otherwise ask
   one decision-ready question, explaining the tension and recommendation.
3. Apply the result throughout the artefact or in-session draft and related
   in-scope material. Update the selected decision/work record, agenda, and
   transcript according to the session plan.
4. Reconcile and reprioritise the remaining agenda before continuing. A direct
   user answer may resolve more than one item; an inferred preference remains a
   proposed outcome until the user accepts it.
5. Report progress proportionately when it helps: distinguish user decisions
   from agent work rather than turning the session into a checklist.

## Candidate exit

When the known agenda is resolved, run a concise self-check against the
completion bar: missing or stale propagation, contradictions, placeholders,
unclear language, and scope drift. Re-enter the loop for material issues.

When the bar is met, recommend the optional four-Cs review in
[review.md](review.md). The user can accept it, proceed without it, continue
shaping, or stop. An environment handler may offer a lifecycle action, but it
remains part of the displayed session plan and follows the user’s approval.

## Watch for

- Asking the user to decide when evidence already supplies a clear answer
- Silently closing a real product or preference decision
- Updating a decision record while leaving affected prose stale
- Treating all outstanding work as equally important
